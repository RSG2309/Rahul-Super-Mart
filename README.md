# B2B Wholesale E-commerce Platform

This is a complete, scalable, and responsive B2B Wholesale E-commerce Platform containing:
- `/backend`: A Node.js, Express, TypeScript, and MongoDB server.
- `/frontend`: A Next.js 15, React 19, Tailwind CSS, and Framer Motion web app.
